v12.1         | 0.5539 | 0.5217 | Fix bug 1 only: elevation wrap in jump filter (inf-pad)

================================================================================
Key findings:
- v12 (with original bugs) remains the best pseudo-LiDAR result (NDS=0.5539)
- Bug 1 fix (elevation wrap): no measurable impact on metrics
- Bug 3 fix (Z-range tightening): hurts performance (NDS -0.0061, mAP -0.0133)
  → Tighter Z-range finds fewer ground candidates; RANSAC correction degrades
- Bug 4 fix (radius limit): slight degradation (NDS -0.0009, mAP -0.0016)
  → Far-range "erroneous" corrections accidentally improved results
- v15 Grid Penetration Filter: +0.0022 NDS, +0.0042 mAP vs v12 — лучший результат
- v15s (20 samp, все камеры): NDS=0.5486 — хуже v15, мало данных для калибровки
- v15s_full (404 samp, все камеры): NDS=0.5492 — чуть лучше, но всё равно хуже v15 (-0.0069)
  → CAM_BACK_LEFT (std=1.66) и CAM_BACK_RIGHT (std=1.26) вносят шум
- v15s_4cam (404 samp, 4 камеры): NDS=0.5554, mAP=0.5263 — почти на уровне v15 (-0.0007 NDS, +0.0004 mAP)
  → исключение 2 ненадёжных камер из scale correction значительно помогает
- Все варианты pseudo-LiDAR всё ещё ниже empty-LiDAR baseline (NDS=0.5709)
  → Domain gap можно закрыть только через fine-tuning BEVDet на pseudo-LiDAR
